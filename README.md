# 7DaysBackup — 七日杀存档自动备份工具

![CI](https://github.com/zhengwuji/7DaysBackup/actions/workflows/ci.yml/badge.svg)
![Release](https://github.com/zhengwuji/7DaysBackup/actions/workflows/release.yml/badge.svg)

> 你负责在废土里浪，它负责给你兜底。

在《七日杀》里，最让人破防的不是被僵尸围殴致死，而是花了一整个周末建的末日堡垒，在一次闪退之后全部归零。7DaysBackup 就是为这个场景而生的——一个驻留在系统托盘的静默备份程序，你只管玩，它只管备份。

**当前版本为 Rust 原生重写版**：无运行时依赖、启动毫秒级、单文件约 7 MB（旧版 Python 实现保留在仓库根目录作参照，见文末）。

## 功能

| 功能 | 说明 |
|------|------|
| 热备份 | 边玩边备份，不需要退出游戏 |
| 定时快照 | 默认每 5 分钟自动备份，间隔自定义（1 分钟 ~ 7 天） |
| 变更检测 | 基于备份时刻的文件清单（mtime + 大小）精确对比，只备份发生变化的存档，不受系统时钟调整影响 |
| 完整性校验 | 每个备份写入后逐条目校验 CRC，杜绝半成品坏档 |
| 版本轮转 | 保留最近 N 个版本 + 尾部每天最新 1 个额外保留 N 天 + 可选备份总量上限（MB）；只有产生新备份后才清理旧备份，最新一份永不自动删除 |
| 备份位置 | 备份保存位置可自定义（可跨盘，默认存在每个存档目录的 backup 文件夹内） |
| 存档位置 | 存档路径可配置，适配服务器自定义存档目录 |
| zip 压缩 | 内置 deflate 压缩，级别 1-9 可调 |
| 一键恢复 | 恢复前检测游戏进程、自动创建安全快照、临时目录中转防半成品；快照列表可见、可再恢复 |
| 失败通知 | 备份/恢复失败弹系统气泡通知，最小化到托盘也不错过 |
| 系统托盘 | 静默运行，双击图标打开设置；菜单支持立即备份 / 暂停备份 / 打开备份文件夹 / 退出 |
| 开机自启 | 默认开启（注册表 Run 键），可在设置中关闭 |
| 存档勾选 | 左侧列表勾选需要监控的存档，不勾的不备份 |
| 单实例 | Windows 命名互斥量，无 PID 复用误判 |

## 快速开始

### 下载安装

1. 前往 [Releases 页面](https://github.com/zhengwuji/7DaysBackup/releases) 下载最新的 `7DaysBackup.exe`（或附带 README 的 zip 包）
2. 放到任意目录双击运行即可，**无需安装**，无任何运行时依赖
3. 开机自启默认开启，程序会驻留系统托盘静默备份

> 也可以用 `--hidden` 参数启动，直接静默到托盘不出窗口。

### 首次运行

程序启动后会自动扫描 `%APPDATA%/7DaysToDie/Saves` 下的存档：

- 左侧列表勾选需要监控的存档（默认自动选中最近备份过的一个）
- 每个存档首次会多备份一次以建立文件清单基准，之后**只备份有变化的存档**
- 备份默认保存在每个存档目录的 `backup` 文件夹内；想统一存放（比如另一个盘），在下方「备份保存位置」选择目录即可

### 日常使用

- **自动备份**：按设定的间隔（默认 5 分钟）检查存档变化，有变化才备份
- **立即备份**：点界面按钮或托盘菜单「立即备份」随时手动备份
- **暂停备份**：托盘菜单可暂停/恢复，暂停期间不检查不备份
- **最小化**：关闭窗口或点「隐藏窗口」都会最小化到任务栏，托盘图标常驻，备份照常进行

### 恢复备份

1. 在「备份历史」列表选中要恢复的时间点，点「恢复选中备份」
2. 程序会先检测游戏是否在运行（运行中会拒绝恢复，防止写坏档），然后自动创建一份**恢复前安全快照**（最多保留 3 份）再执行恢复
3. 快照显示在备份历史下方的折叠区，万一恢复错了还可以再恢复回去
4. 右键任意备份可查看存放位置、打开所在文件夹、复制路径、删除该备份

### 托盘菜单

右键托盘图标：**显示设置** / **立即备份** / **暂停备份** / **打开备份文件夹** / **退出**。窗口最小化时同样有效，备份失败会弹系统气泡通知。

### 版本保留规则（自动清理）

每次产生新备份后自动清理，规则如下：

| 规则 | 说明 |
|------|------|
| 保留最近 N 个版本 | 默认 10 |
| 每天最新一份额外保留 | 超出 N 个后，最近 7 天每天留一份最新快照 |
| 总量上限（可选） | 超过设定 MB 数时从最旧开始删，直到达标（至少留 1 份） |
| **最新一份永不删除** | 无论怎么设置，最新备份都不会被自动清理；且只有产生了新备份才会触发清理，不备份就不删 |

### 配置文件

自动生成于 `%APPDATA%/7DaysBackup/config.json`（自动迁移旧版 Python 的 manifests.json）：

```json
{
  "backup_interval_seconds": 300,
  "max_backup_versions": 10,
  "daily_keep_days": 7,
  "max_total_size_mb": 0,
  "compression_level": 6,
  "save_path": "",
  "backup_output_path": "",
  "auto_start": true,
  "minimize_to_tray": true
}
```

## 从源码构建

```bash
cd rust
cargo build --release
# 输出: rust/target/release/7DaysBackup.exe
cargo test        # 运行单元测试
```

推送到 GitHub 后 CI 会自动编译：每次代码变更自动跑测试并构建 exe（在 Actions 运行页面可下载）；发布正式版本时打 `v*` 标签，自动创建 Release 并附上 exe、zip 和 CHANGELOG 中的中文更新内容。
